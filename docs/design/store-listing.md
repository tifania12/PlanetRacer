# 스토어 문구 초안 (M-12)

2026-09-16 야간 세션 초안. 근거는 `docs/design/monetization.md`(파는 것 2장, 안 파는 것 서두,
Steam 리뷰 방어 6장) — 숫자·SKU가 거기서 바뀌면 이 문서도 같이 고친다.
아직 스크린샷·트레일러가 없어 그 자리는 비워 둔다. 실제 등록 전에 Tifania가 다듬을 초안이다.

## 원칙 — 첫 문단에 파는 것과 안 파는 것을 같이 적는다

monetization.md 6장: "무료+인앱 방치형은 Steam에서 기본적으로 의심받는다. 첫 문단에
파는 것 전부와 안 파는 것 전부를 그대로 나열하는 것이 가장 좋은 방어다." 그래서 아래 두
스토어 문구 모두 **첫 문단이 사양 나열**이다 — 감성 문구보다 이 나열이 우선이다.

---

## 1. Steam 페이지

### 1-1. 짧은 설명 (검색 결과·태그 옆에 뜨는 한 줄)

> 보석 행성을 돌며 채굴하고, 캔 광물로 레이싱카를 만들어 그랑프리에서 겨루는 방치형 레이싱 게임.
> 승패는 오직 부품 스탯으로 갈린다 — 부품은 돈으로 살 수 없다.

### 1-2. 상세 설명 첫 문단 (사양 나열 — 리뷰 방어의 핵심)

> **이 게임에서 돈으로 살 수 없는 것: 레이싱카 부품, 채굴차 부품, 공구 상자, 상자 열쇠,
> 청사진, 연료, 대전권. 확률형 뽑기 없음. 시즌 패스 유료 트랙에도 전투력 보상 없음.**
> 레이스 결과를 정하는 건 오직 레이싱카 부품의 스탯이고, 부품은 전부 플레이(레이스 승리·
> 채굴·제작)로만 얻는다. 파는 것은 시간 단축(화물칸 확장·오프라인 연장·채굴 가속)과
> 겉모습(스킨)뿐이다.

### 1-3. 상세 설명 본문 (초안 — 순서대로 채워 넣을 문단)

1. **한 줄 소개** — 보석 이름의 행성을 무대로, 방치 채굴 → 레이싱카 제작 → 그랑프리 우승 →
   다음 행성으로 이어지는 루프.
2. **핵심 재미** — 채굴차가 알아서 돌아가는 동안 쌓이는 광물, 그걸로 만드는 내 레이싱카,
   그 차로 뛰는 실시간 그랑프리. (스크린샷 자리 — 채굴 화면 / 제작 화면 / 레이스 결과 화면)
3. **Steam 판이 다른 점** — 광고 없음, 구독 대신 서포터 팩(영구, 일회성), 화물칸 기본 상한이
   모바일보다 1.5배 넉넉함. (근거: monetization.md 4장)
4. **파는 것 전체 목록** (1-2의 요약을 표로 풀어서 재확인 — 가격은 얼리 액세스 후 조정 가능 문구 포함)
   - 화물칸 확장 3단계 (영구)
   - 오프라인 상한 연장 (영구)
   - 채굴 가속 패스 (30일 구독형, 산출량만 ×2, 등급엔 영향 없음)
   - 서포터 팩 (영구, 통행증 혜택)
   - 스킨 (스탯 0)
5. **모바일과의 교차 대전** — 대전 상대가 모바일이든 Steam이든, 결과를 가르는 건 레이싱카
   부품 스탯뿐이라고 명시. ("Steam 판이 유리하다"는 오해를 사전에 차단)
6. **마무리 — 반복 문구** — "시간은 팔고 힘은 팔지 않습니다."

### 1-4. 태그 후보

방치형(Idle), 레이싱, 수집, 시뮬레이션, 캐주얼, 크래프팅. (실제 Steam 태그 목록에서
등록 시점에 맞는 것으로 다시 고를 것 — 지금은 후보만)

## 2. 모바일 스토어 (Google Play / App Store)

Steam보다 짧고 감성 위주로 가되, "안 파는 것" 한 줄은 그대로 가져간다 — 모바일도 같은
약속이라는 걸 알려야 스타터 팩 전환에 도움이 된다(monetization.md 2-1).

### 2-1. 짧은 설명 (Google Play용, 80자 내외)

> 보석 행성 방치 채굴 → 레이싱카 제작 → 그랑프리 우승. 승부는 실력과 부품, 돈이 아닙니다.

### 2-2. 긴 설명 초안

1. 도입 — 방치 채굴이 쌓이는 동안 다음 레이스를 준비하는 루프 소개.
2. 핵심 순환 — 채굴 → 화물칸이 차면 정제 or 레이스로 비우기 → 부품 제작·강화 → 그랑프리 →
   다음 행성.
3. **"부품은 팔지 않습니다"** 한 줄 — 레이싱카 부품·채굴차 부품·공구 상자·상자 열쇠·청사진·
   연료·대전권은 상점에 없다고 명시. 확률형 뽑기도 없다.
4. 파는 것 — 화물칸 확장, 오프라인 상한 연장, 채굴 가속 패스, 행성 통행증(구독), 스킨.
   전부 "더 빨리" 또는 "겉모습"이지 "더 세게"가 아니라는 문장으로 마무리.
5. 광고 안내 — 보상형 광고만 있고(하루 최대 10회, 원할 때만), 광고 제거 상품으로 끌 수 있음.

### 2-3. 키워드 후보

방치형 게임, 레이싱 게임, 채굴 게임, 크래프팅, 보석, 그랑프리

## 3. 남은 것

- 스크린샷·트레일러 자리는 실제 화면(uGUI 이사 U-08까지 끝난 뒤)이 안정되면 채운다.
- 가격 숫자는 얼리 액세스 2주 지표로 재조정 예정(monetization.md 2장 서두) — 그때 이 문서의
  1-3-4 표도 같이 갱신.
- 영문 번역은 아직 없음. Steam 글로벌 노출을 결정하면(`docs/decisions.md`에 올릴 것) 그때 추가.
- 실제 등록 문구는 Tifania가 이 초안을 다듬어 확정한다. 세션이 임의로 최종본으로 올리지 않는다.
