# 지인 테스트 배포 안내문 (D19-M, proto-1)

D19-N(9/30) ~ D22(10/3) 지인 테스트에서 Tifania가 카카오톡 등으로 **그대로 복사해서 보낼 수 있게**
쓴 안내문이다. 아래 "여기부터 복사" ~ "여기까지" 사이가 실제로 보낼 메시지, 그 위아래는 이 문서
자체의 설명이다.

## 언제 쓰나

- D19-N에 Tifania가 Unity에서 태그 `proto-1`로 APK를 뽑아 지인 5명에게 배포할 때, 이 메시지를 같이 보낸다.
- 테스트 기간은 D20~D22(10/1~10/3), 3일이다.
- D23-N(10/4)에서 세션 로그·피드백을 모아 관문 판정을 하니, 테스트가 시작되면 되도록 빨리
  피드백을 받아 두는 게 좋다 — 3일째 밤에 몰아서 받으면 정리할 시간이 부족하다.

## 안내문을 쓰면서 참고한 것

- `docs/design/session-log-format.md` — `feedback.txt`는 저장 버튼을 누르는 순간 **클립보드에도
  자동 복사된다.** 지인이 파일 탐색기를 뒤질 필요 없이, 게임 안에서 저장 버튼 누르고 카카오톡에
  붙여넣기만 하면 된다는 뜻이라 안내문에도 그렇게만 시켰다.
- 같은 문서 "알려진 한계" — 서버 업로드가 없어서 피드백은 결국 사람이 직접 보내야 한다.
  `session_log.csv`(접속 시각·시간)는 파일 탐색기/ADB 접근이 필요해 일반 지인에게 시키기
  부담스러워서, 안내문에서는 뺐다 — 대신 "하루에 몇 번, 얼마나 했는지" 정도는 말로 물어보게
  했다(D23-N이 정확한 숫자가 필요하면 그때 APK를 회수해 로그 파일을 직접 꺼내는 방법도 있다).
- `docs/GDD.md` — 게임 소개 한 줄과 현재 얼리 액세스 상태(쿼츠 행성 하나, P1 프로토타입 단계)를
  과장 없이 그대로 적었다. "아직 프로토타입"이라는 걸 먼저 말해야 피드백이 "왜 이게 없냐"가 아니라
  "이 정도면 되나"로 나온다.
- 설치 방법은 사이드로드 APK 공통 안내(출처를 알 수 없는 앱 허용)로 썼다 — 실제 배포 방법
  (카카오톡 파일 전송인지 구글 드라이브 링크인지)은 D19-N에서 Tifania가 정할 일이라 이 문서는
  "APK 파일을 받으면"으로만 적어 뒀다.

## 이 문서가 안 다루는 것

- **실제 배포 경로**(카카오톡/드라이브/기타)와 서명 문제(안드로이드 미확인 앱 설치 시 경고 문구가
  기기·버전마다 다름) — 그때 가서 Tifania가 실제로 설치해 보고 필요하면 이 문서에 캡처를 추가한다.
- D23-N 관문 판정 자체(무엇을 성공으로 볼지) — 그건 `docs/backlog.md` D23-N/D24와
  `docs/decisions.md` 몫이다. 이 문서는 피드백을 "모으는" 방법만 다룬다.

## 여기부터 복사 (카카오톡 등으로 지인에게 보낼 메시지)

안녕! 요즘 만들고 있는 게임 초기 버전 테스트 좀 부탁해도 될까?

**게임 소개**
"보석 행성 레이서" — 방치형 채굴 + 레이싱 게임이야. 채굴차가 알아서 광물을 캐 오고, 그 광물로
채굴 장비나 레이싱카를 강화해서 레이스에서 이기는 구조. 지금은 **아주 초기 프로토타입**이라
행성이 첫 번째(쿼츠) 하나뿐이고, 그래픽이나 밸런스도 다듬는 중이야 — "이게 재밌나 아닌가"
정도만 봐줘도 충분해!

**설치 방법 (안드로이드)**
1. 같이 받은 APK 파일을 폰에 저장
2. 파일을 눌러서 설치 — "출처를 알 수 없는 앱" 경고가 뜨면 허용하고 계속 진행 (이 앱만 예외로 두는
   거라 걱정 안 해도 돼, 테스트용이라 아직 정식 스토어에 안 올라간 것뿐)
3. 설치되면 "PlanetRacer" 아이콘으로 실행

**뭘 해보면 되나**
- 튜토리얼 따라 채굴 → 강화 → 레이스 순서로 한 바퀴 돌아봐 줘
- 그 다음엔 그냥 편하게 몇 번 켜서 해봐 (하루에 몇 번, 한 번에 몇 분 정도 했는지 대충 기억해 두면
  나중에 물어볼게)
- 3일 정도(오늘부터 모레까지) 편할 때 틈틈이 해주면 돼. 매일 꼭 해야 하는 건 아니고!

**피드백 남기는 법**
- 게임 안 설정 메뉴에 "피드백" 버튼이 있어. 눌러서 느낀 점 적고 저장하면 **자동으로 클립보드에
  복사**돼 — 그거 그대로 나한테 카톡으로 붙여넣기만 해주면 끝!
- 뭐든 좋아: 헷갈렸던 부분, 재미없었던 부분, 버그(이상하게 멈추거나 화면이 깨지는 거), "이런 게
  있으면 좋겠다" 같은 것도 다 환영
- 짧게 여러 번 보내도 되고, 마지막에 한 번에 정리해서 보내도 돼

바쁠 텐데 시간 내줘서 진짜 고마워! 궁금한 거 있으면 언제든 물어봐.
