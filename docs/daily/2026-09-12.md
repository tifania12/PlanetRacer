## 막힌 것·결정 필요
- SurfaceMover는 고정된 회전축 둘레로 도는 방식이라 지금 시작 위치(적도 부근) 기준으로는 실제 극점을 지나가지 않는다. 극점 근처에서 방향이 뒤집히는 문제(LookRotation flip)를 직접 재현해서 검증은 못 했다 — backlog D01-M에서 회전축을 극점 쪽으로 두고 몇 바퀴 돌려보면서 큐브가 갑자기 홱 도는지 확인해 달라. 문제 있으면 `SurfaceMover.ApplyTransform()`의 대체 접선 계산 로직을 다시 봐야 한다.
- Unity 에디터가 이 환경에 없어서 `BootstrapScene.cs`가 실제로 컴파일·실행되는지 못 봤다. `Shader.Find("Universal Render Pipeline/Lit")`, `EditorSceneManager.NewScene` 등은 URP 프로젝트라면 될 거라고 보는데, 확실친 않다 — 아침 확인 필요.
