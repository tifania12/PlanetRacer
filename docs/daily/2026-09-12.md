- 원인: `Assets/Scripts/Data/BalanceTable.cs(48,21) error CS0118: 'Planet' is a namespace but is used like a type`.
  `Assets/Scripts/Planet/`(SurfaceMover 등)이 네임스페이스를 `GemRacer.Planet`으로 쓰는데,
  `BalanceTable.cs`는 `using GemRacer.Core;`만 걸어 두고 bare `Planet`(코어 모델)을 그대로 썼다.
  C#은 같은 이름의 형제 네임스페이스를 using으로 가져온 타입보다 먼저 찾기 때문에 충돌이 났다.
  Core.Tests 프로젝트에는 `GemRacer.Planet` 네임스페이스 자체가 없어서(Assets/Scripts를 안 씀) 여태 안 걸렸다.
- 수정: `using CorePlanet = GemRacer.Core.Planet;` 별칭을 추가하고 `ToPlanets()` 안의 세 곳을 `CorePlanet`으로 바꿈.
  같은 파일의 `Course`/`Part`는 겹치는 네임스페이스가 없어서 그대로 둬도 된다(확인함).
