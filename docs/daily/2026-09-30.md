#### 절차 메모 — `git pull --rebase`가 막혀서 stash로 비켜 갔다

시작할 때 `git status`에 `PlanetRacer/Assets/Fonts/Pretendard-Regular SDF.asset` 한 줄이
unstaged로 떠 있어 `git pull --rebase`가 `cannot pull with rebase: You have unstaged changes`로
거절당했다. **Unity가 폰트 에셋을 건드린 것이라 세션이 커밋할 것이 아니다.**
PowerShell에서 그 파일만 `git stash push` → `pull --rebase`(`Already up to date`) →
`git stash pop`으로 **원래 상태 그대로 돌려놓았다.** 지금도 그 한 줄은 unstaged로 남아 있다.
다음 세션도 같은 줄을 볼 것이다 — 커밋하지 말고 이렇게 비켜 가면 된다.
