    git push origin origin/claude/dev:main

**그리고 이게 더 큰 문제 하나를 드러냈다 — 빌드가 계속 취소돼서 승격 조건이 거의 안 채워진다.**

실패로 잘못 읽기 쉽다 — 결론은 API나 실행 페이지로 봐야 한다).
세션마다 "직전 빌드가 아직 도는 중"이라 성실하게 승격을 보류하고, 그 사이 main이 계속 뒤처진다.
