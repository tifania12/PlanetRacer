# 보석 행성 레이서 — 기획 요약 (v0.2, 2026-09-10)

전체 문서는 Claude 아티팩트 "보석 행성 레이서 기획서". 이 파일은 코드 작업 중 참고용 요약.

## 한 줄
보석 이름의 행성을 하나씩 정복하는 방치형 레이싱. 채굴차는 알아서 광물을 파고, 플레이어는 그 광물을 채굴에 더 쓸지 레이싱카에 쓸지만 정한다.

## 코어 루프 (v0.3 — 상호 강화 나선, 상세는 docs/design/core-loop.md)
탐험(자동, 오프라인 포함 → 보물·광맥 발견) → 채굴(선택해서 캠) → 광물로 채굴 도구·채굴차·레이싱카 강화 → 레이스 승리로 ★채굴차 전용 부품★ 획득 → 더 빨리·더 높은 등급 채굴 → 레이싱카 더 강화 → 상위 레이스 승리 → ... → 그랑프리 1등 → 다음 행성.
두 축이 서로를 먹인다. 채굴만 파면 상위 보물이 안 캐지고(레이스 부품 필요), 레이싱만 파면 상위 레이스 출전이 안 된다(그 행성 광물 세트 필요).

## 행성 (얼리 액세스 6개)
쿼츠(튜토리얼) → 루비(고온) → 사파이어(저온·저접지) → 아쿠아마린(액체) → 주사(독성) → 라피스 라줄리(저중력·희박, 엔드게임).
행성 광물로만 그 행성 부품을 만든다. 같은 행성 부품 3개 = 세트 효과 = 그랑프리 출전 조건.

## 채굴 장비 (행성 이동 후에도 유지)
곡괭이→드릴→레이저(30레벨), 화물칸(10, 4h→12h 오프라인 상한), 채굴차 엔진(10), 탐지기(5, 보석 원석), 제련소(5).

## 레이싱카
슬롯 5 + 특수 모듈 1. 등급 C/B/A/S. 강화 +10 실패 없음, 비용 가파름.

## 레이스 (행성당 10개)
로컬 5(연료1, 녹슨 상자) / 서킷 3(연료2, 강철) / 챌린지 1(연료3, 티타늄) / 그랑프리 1(연료5, 워프).
연료 10분에 1 회복, 최대 10. 결과는 출전 전에 스탯으로 결정(RaceSimulator), 연출은 그 뒤.

## 공구 상자
게임 안에서만 획득. 유료 판매 없음. 천장 있음(강철 30개 A 확정, 티타늄 10개 S 확정). 등급이
실제로 주는 것은 채굴차 부품(레벨업, `docs/decisions.md` T-07 A안) — 레이싱카 부품 청사진이 아니다.

## 온라인
일일 광맥(하루 3회, 채굴+레이스 복합, 요일 로테이션). 유저 대전(비동기, 하루 5회, 승리 시 상대 부품 청사진, 패자 손실 없음). 모바일·PC 교차 대전, 단일 풀.

## 수익 (결정 필요)
A안 추천: 양쪽 무료 + 인앱 3종(광고 제거·스킨·채굴 패스). 부품·상자·연료는 팔지 않는다.

## 기술
Unity 6 URP 로우폴리 3D. 세로 9:16 단일 UI, PC는 세로 창. 코어는 순수 C#(서버 공유). 백엔드 Nakama 또는 PlayFab. 콘텐츠는 전부 CSV→ScriptableObject.
